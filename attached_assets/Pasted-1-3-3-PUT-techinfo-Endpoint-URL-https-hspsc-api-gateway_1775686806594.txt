1.3.3 [PUT] /techinfo
Endpoint URL:  https://hspsc-api-gateway-qa.stage.nextgen.shs.com/v1/api/techprofile/api/techinfo

HTTP Method: PUT

Data Format: JSON

Description: Through this endpoint, following information for a tech can be changed

Profile - Contact No and Email

Assigned truck

Address

Tech Replenishment information [TBD]

Request Body:

Column

Required (Y/N)

Format

Comments

techLdapId

Y

Alphanumeric, Max length 8

Requesting Technician’s LDAP id

upserts

Y

Upserts

Section containing all inserts and updates to perform

Upserts

Required (Y/N)

Format

Comments

techId

N

String

Pass this if need to update techId for a technician. Pass ““ if you want to remove techId of requesting tech

truckNo

N

String

Truck no to be assigned to this tech (represented by techLdapId). Cannot be assigned if already assigned to another tech.

Pass ““ if you want to remove current truck assignment for requesting tech

contactNo

N

String

Phone number.

Pass ““ if you want to remove phone no for requesting tech

email

N

String

Email

Pass ““ if you want to remove email for requesting tech

addresses

N

List of TechAddress

 

updatedBy

Y

String

Required. Ldap Id of associate making this update 

TechAddress

Required (Y/N)

Format

Comments

addressType

Y

String

One of P, D, R, A where 

P=PRIMARY

R=RE_ASSORTMENT

D=DROP_RETURN

A=ALTERNATE

shipToName

N

String

 

addrLine1

Y

String

Max length 30

addrLine2

N

String

Max length 30

city

Y

String

 

stateCd

Y

String

zipCd

String

distUnitNo

N

 

7 Characters
